# xo_notes
a discord bot that helps you organize notes, subscribe to server notes, make checklists, and link channels/servers

## notes
> * !note ʹʹtitleʹʹ content`` - Creates a new note"
> * !list_notes`` - Shows all saved notes"
> * !delete_note ʹʹtitleʹʹ`` - Deletes a note"
> * !conversation_note [minutes]`` - Record channel messages"
> * !show_note ʹʹtitleʹʹ`` - Displays a specific note"
>> * !subscribe ʹʹtitleʹʹ`` - Subscribe to note updates"
>> * !unsubscribe ʹʹtitleʹʹ`` - Unsubscribe from updates"
>> * !my_subscriptions`` - List notes you're subscribed to"
* !thread_note [thread]`` - Create note from thread messages"
>> * !auto_note [thread]`` - Toggle auto-note for thread"



## checklists
> * !checklist ʹʹtitleʹʹ item1, item2, item3`` - Creates a checkable checklist"
* !show_checklist ʹʹtitleʹʹ`` - Displays a specific checklist"
* !list_checklists`` - Shows all saved checklists"
* !delete_checklist ʹʹtitleʹʹ`` - Deletes a checklist"
